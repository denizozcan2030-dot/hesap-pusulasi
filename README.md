# Sepet Rotası (prototip) · Sepet Rotası (prototype)

**🇹🇷 Türkçe** · [English below](#english)

Market fiyatlarını karşılaştıran uygulamalar için bir **özellik önerisi prototipi**: alışveriş listeni yaz, belirsiz ürünlerde çeşidi sen seç, en uygun sepeti ve markete gitmeden "bir şey unuttum mu?" kontrolünü gör.

▶️ **Canlı demo:** https://denizozcan2030-dot.github.io/sepet-rotasi/

- Tüm ürün, fiyat ve teslimat verileri **örnektir (demo verisi)**; gerçek fiyat değildir.
- Hiçbir kamu kurumuyla resmî bir bağı yoktur ve onların onayını taşımaz.
- Yapay zekâ desteğiyle geliştirilmiş bağımsız bir prototiptir.
- Bu herkese açık demoda fotoğraf, fiş ve Deno asistanı cevapları **örnektir (simüle)**: seçilen görsel gerçekten okunmaz, hazır örnek sonuç gösterilir. Ortak liste bu demoda tek tarayıcıda simüle edilir (gerçek paylaşım yoktur).
- Fiyatları ve toplamları yapay zekâ değil, uygulamanın kural motoru hesaplar.
- Sayfa dışarıya hiçbir bağlantı yapmaz; yazı tipi (Figtree, SIL Open Font License 1.1) sayfanın içine gömülüdür.

Telefonda tarayıcı menüsünden **"Ana ekrana ekle"** diyerek uygulama gibi kullanılabilir (web uygulaması; mağaza uygulaması değildir). Çalıştırmak için `index.html` dosyasını bir tarayıcıda açmak yeterlidir (kurulum gerekmez). Tasarım belgeleri `docs/` klasöründedir.

## English

A **feature-proposal prototype** for market price comparison apps: type your shopping list, pick the exact product where a line is ambiguous, see the cheapest basket, and run an "did I forget something?" check before leaving the store.

▶️ **Live demo:** https://denizozcan2030-dot.github.io/sepet-rotasi/

- All products, prices and delivery data are **sample (demo) data**, not real prices.
- It has no official affiliation with, and is not endorsed by, any public institution.
- It is an independent prototype developed with AI assistance.
- In this public demo, photo, receipt and "Deno" assistant responses are **simulated**: the image you choose is not actually read; a canned sample result is shown. The shared list is simulated in a single browser here (no real sharing).
- Prices and totals are computed by the app's rule engine, not by AI.
- The page makes no external requests; the font (Figtree, SIL Open Font License 1.1) is embedded in the page.

On a phone you can use the browser menu's **"Add to Home screen"** to run it like an app (it is a web app, not an app-store app). To run it, just open `index.html` in a browser (no installation). Design documents are in `docs/` (Turkish).
